# Week 2 – C Programming and GCC

This folder contains the practical work completed during Week 2 of the ST5003CMD Operating Systems, Security and Networks module.

## Lab 2

Lab 2 focuses on the basics of C programming and working with the GCC compiler in a Linux environment.

### Topics Covered

- Basic C program structure
- Printing output using `printf()`
- Taking user input using `scanf()`
- Formatted output and different data types
- Program return values and exit status
- Checking exit status using `echo $?`
- GCC compilation
- The four stages of compilation:
  - Preprocessing
  - Compilation
  - Assembly
  - Linking

### Lab 2 Contents

The `Lab 2` folder contains the lab report, C source files, and supporting documentation used during the practical work.

### Learning Outcome

This practical work provided hands-on experience with writing, compiling, and executing C programs in Linux. It also helped develop an understanding of how GCC processes C source code through the different compilation stages before producing an executable program.
